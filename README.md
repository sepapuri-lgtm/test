# 영수증 파일명 변환기 (Receipt Renamer)

카드 영수증 이미지(JPG·PNG·HEIC·WEBP·BMP)와 PDF를 읽어 **사용자·결제일·금액·가맹점**을 추출하고,
`20261007_홍길동_₩45,000_스타벅스.jpg` 같은 이름으로 일괄 정리하는 Windows 데스크톱 프로그램입니다.
해외 결제는 `20260904_김민배_$22.00_Anthropic.pdf`처럼 결제 통화를 그대로 씁니다.

요구사항 문서: *PRD: 카드 영수증 파일명 자동 변환기* (Claude Docs)

## 사용 방법

1. `ReceiptRenamer.exe`를 실행하고 영수증 폴더나 파일을 창에 끌어다 놓습니다.
2. 위쪽에서 **추출 방식**을 고릅니다.
   - **AI (Claude)**: 정확도가 높습니다. Claude API 키가 필요하고, 처음 한 번 외부 전송 동의를 받습니다.
   - **오프라인 OCR**: Windows 내장 OCR을 씁니다. 인터넷·API 키가 필요 없고 영수증이 PC 밖으로 나가지 않습니다. 결과는 모두 '확인 필요'로 표시됩니다.
3. **▶ 추출 시작**을 누릅니다. 확인이 필요한 행은 **노란색**, 빈 칸이나 실패한 행은 **주황색**으로 표시됩니다.
4. 표시된 행을 골라 오른쪽 미리보기(마우스를 올리면 돋보기, 휠로 배율 조절)와 비교하며 칸을 고칩니다.
   금액은 `$22.00`, `22 달러`, 시각은 `오후 2:32`, `14:32`, `1432` 모두 받습니다.
5. **✔ 변경 적용**을 누르면 영수증 폴더 안에 `20261009-1530-변환완료` 폴더가 생기고, 새 이름의 사본과
   `영수증_요약.txt`·`영수증_요약.xlsx`가 그 안에 저장됩니다. 원본은 건드리지 않습니다.
6. 잘못 적용했으면 **↶ 되돌리기**로 마지막 적용을 취소합니다(복사 모드는 만든 사본만 지움).

### 사용자 매핑표

영수증에 이름이 없으면 카드 끝번호로 사용자를 찾습니다. **사용자 매핑표** 버튼에서 한 줄에 `카드번호,이름`으로 적습니다.

```
2580,김민배        ← 끝 4자리
845*,홍길동        ← 가려진 자리는 *
4289****,김민배    ← 앞 4자리 (카카오T처럼 끝번호가 없는 영수증용, 항상 확인 필요)
```

쉼표 대신 탭(엑셀에서 복사)·공백·전각 쉼표도 됩니다. 저장 위치: `%APPDATA%\receipt_renamer\users.csv`

사용자를 정하는 순서는 **직접 고친 값 → 영수증의 결재자·서명 이름 → 매핑표(카드번호) → 영수증에 적힌 이름**입니다.
`845*`처럼 후보가 둘 이상이면 틀린 이름을 넣지 않도록 비워 둡니다.

### 파일명 규칙

기본값은 `{결제일}_{사용자}_{금액원화}_{가맹점}`입니다. 쓸 수 있는 변수:

| 변수 | 예 (원화) | 예 (달러) |
|---|---|---|
| `{결제일}` | 20261007 | 20260904 |
| `{시각}` | 오후 3시01분 | |
| `{사용자}` `{가맹점}` `{카드끝번호}` `{카드사}` | 홍길동 · 스타벅스 · 1234 · 신한 | 김민배 · Anthropic · 8452 · Visa |
| `{금액}` / `{금액콤마}` / `{금액원화}` | 45000 / 45,000 / ₩45,000 | 22.00 / 22.00 / $22.00 |
| `{결제금액}` `{업종}` | 부가세 포함 금액 · 숙박/음식점/기타 | |
| `{원본명}` `{순번}` | IMG_4821 · 001 | |

- 숙박·음식점 원화 영수증은 `{금액}`류 변수와 요약 합계에 **부가세를 뺀 금액(공급가액)**을 씁니다(160,000원 → ₩145,455).
- Windows에서 쓸 수 없는 문자(`\ / : * ? " < > |`)는 지우고, 같은 이름이 있으면 `_2`, `_3`을 붙입니다.
- 추출하지 못한 값은 `미확인`으로 채웁니다.

## 설치·빌드

### 실행 파일 받기

GitHub Actions의 **Windows 실행 파일 빌드** 작업이 실행될 때마다 `ReceiptRenamer-exe` 아티팩트로
`ReceiptRenamer.exe`를 만듭니다.

### 직접 빌드 (Windows 10/11)

Python 3.12 이상을 설치한 뒤:

```bat
build_exe.bat
```

`dist\ReceiptRenamer.exe`가 만들어집니다. `ReceiptRenamer.exe --selftest`로 부품·OCR·API 연결을 점검할 수 있습니다.
개발 중에는 `run_gui.bat`으로 바로 실행합니다.

### 오프라인 OCR 준비

Windows **설정 → 시간 및 언어 → 언어 및 지역**에서 **한국어**를 추가하고 **광학 문자 인식(OCR)** 기능을 설치해야 합니다.
없으면 프로그램이 안내합니다. 텍스트가 있는 PDF는 OCR 없이 텍스트층을 바로 읽습니다.

### 명령줄

```bat
ReceiptRenamer.exe extract D:\영수증\10월 -o 미리보기.csv
ReceiptRenamer.exe apply D:\영수증\10월 --mode copy
ReceiptRenamer.exe undo
```

## 코드 구조

| 파일 | 역할 |
|---|---|
| `receipt_renamer/gui.py` | tkinter 화면: 검토 표, 상세 칸, 돋보기, 매핑표·설정 창 |
| `receipt_renamer/extractor.py` | 추출 흐름 (텍스트층/이미지 → AI 또는 오프라인 → 검증·사용자 판정), 병렬 처리 |
| `receipt_renamer/ai.py` | Claude API 추출 (`claude-opus-5-5`, effort low, JSON 스키마 응답, 거절 시 서버측 대체 모델) |
| `receipt_renamer/ocr.py` | Windows 내장 OCR + 보정 재판독(종이 자르기·대비·확대·회전) |
| `receipt_renamer/rules.py` | 정규식 규칙 추출 (날짜·시각·금액·통화·카드번호·가맹점·결재자·업종) |
| `receipt_renamer/normalize.py` | 가맹점 표기 정리, 매핑표로 사용자 찾기, 부가세 제외 금액 |
| `receipt_renamer/naming.py` | 파일명 템플릿, 금액·시각 형식, 금지 문자·중복 처리 |
| `receipt_renamer/output.py` | 결과 폴더, 복사/이름 변경, 파일 날짜, 되돌리기, 메모장·엑셀 요약 |
| `receipt_renamer/config.py` | 설정·매핑표 (`%APPDATA%\receipt_renamer`) |

테스트: `python -m pytest`

## 개인정보

- 카드번호는 끝 4자리(필요하면 앞 4자리)만 저장합니다.
- 설정·API 키·매핑표·변경 기록은 이 PC의 `%APPDATA%\receipt_renamer`에만 저장합니다.
- AI 추출을 쓸 때만 영수증이 Claude API로 전송되며, 처음 한 번 동의를 받습니다.
